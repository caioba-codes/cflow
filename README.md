# cflow

This is my personal workflow. As of now it's a combination of [pstack](https://github.com/cursor/plugins/tree/main/pstack), Matt Pocock's skills and Notion's 10x dev skills, adapted to Claude Projects. If you think it's shit, open a PR. I'd appreciate it.

**Install**

```bash
git clone https://github.com/caioba-codes/cflow && cflow/scripts/install.sh
```

**Learn how to use it**

```
/explain-flow cflow
```

This creates an HTML page explaining 3 things:

1. Prerequisites for my workflow
2. A step-by-step example of a feature
3. A one-screen cheat sheet of the commands you type, to keep open next to you

It opens on the setup part until you click "I'm set up", then always on the cheat sheet. Mine is at [`skills/explain-flow/references/how-cflow-works.html`](./skills/explain-flow/references/how-cflow-works.html). And this skill works for any workflow btw: `/explain-flow <your workflow>`.
