# cflow

Skills that make Claude Code and Codex work like a careful engineering team.

**Install**

```bash
git clone https://github.com/caioba-codes/cflow && cflow/scripts/install.sh
```

**Learn how to use it**

```
/explain-flow cflow
```

**Use it**

```
/setup-cflow            # once: pick your models
/cflow <your task>      # every task
/cflow-help             # not sure which skill fits
```
